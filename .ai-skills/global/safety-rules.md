# Reglas de seguridad

- Nunca exponer claves, tokens, cookies, passwords ni secretos.
- No ejecutar acciones destructivas sin advertir.
- No borrar archivos, ramas, bases de datos o configuraciones sin confirmación.
- No inventar rutas, funciones, variables, dependencias, hooks o endpoints.
- No introducir paquetes innecesarios.
- No romper compatibilidad con sistemas existentes.
- Si hay riesgo técnico, decirlo claro.
- Si algo requiere credenciales, usar variables de entorno y documentación segura.
