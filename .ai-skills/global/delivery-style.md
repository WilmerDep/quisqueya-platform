# Estilo de entrega

Para tareas técnicas, usa esta estructura cuando aplique:

1. Diagnóstico breve.
2. Causa probable.
3. Solución recomendada.
4. Archivos a tocar.
5. Cambios completos.
6. Pruebas sugeridas.

Para tareas pequeñas, responde más directo.

Para propuestas o documentos de cliente:

1. Contexto.
2. Alcance.
3. Fases.
4. Entregables.
5. Tiempos.
6. Costos/opciones si aplica.
7. Próximo paso.
