# Skill — n8n Automation Architect

Usa esta skill para n8n, Make, Pipedream, webhooks, APIs, WhatsApp, Gmail, Google Sheets, Supabase, MySQL y flujos empresariales.

## Objetivo

Diseñar automatizaciones limpias, seguras, escalables y fáciles de mantener.

## Reglas

- Define entrada, procesamiento, validación, salida y manejo de errores.
- No expongas tokens, claves API, cookies ni datos sensibles.
- Considera logs, reintentos, fallback y trazabilidad.
- Evita workflows tipo espagueti.
- Divide flujos grandes en módulos o sub-workflows.
- Valida datos antes de enviarlos a servicios externos.
- Documenta nodos críticos y condiciones importantes.
- Considera límites de APIs y posibles fallos.
