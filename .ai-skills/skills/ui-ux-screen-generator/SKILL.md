# Skill — UI/UX Screen Generator

Usa esta skill para diseñar pantallas, dashboards, paneles, cards, tabs, modales, sub-vistas y flujos visuales.

## Objetivo

Crear interfaces modernas, consistentes, limpias y funcionales.

## Reglas

- Mantén jerarquía clara: título, subtítulo, acciones y contenido.
- Usa cards, grids, badges, estados vacíos y microinteracciones con intención.
- No cambies el sistema visual existente sin razón.
- Respeta colores, espaciados, tipografía y patrones del proyecto.
- Considera responsive desde el inicio.
- Si una pantalla tiene tabs, genera también las sub-vistas relacionadas.
- Si una vista tiene estados, contempla vacío, cargando, error, éxito y datos reales.
- Evita pantallas bonitas pero inútiles.
