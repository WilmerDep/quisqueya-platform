# Skill — Web App Builder

Usa esta skill para crear o mejorar aplicaciones web con React, Next.js, JavaScript, TypeScript, Tailwind, APIs y paneles administrativos.

## Objetivo

Construir aplicaciones web modernas, mantenibles y listas para crecer.

## Reglas

- Analiza arquitectura antes de crear componentes.
- Respeta rutas, componentes, hooks, servicios y estilos existentes.
- Separa UI, lógica, servicios y datos.
- Usa Next.js cuando el proyecto requiera SSR, SEO, routing avanzado o backend integrado.
- Usa React SPA cuando el proyecto sea más simple o esté embebido en otra plataforma.
- Evita sobreingeniería.
- Considera estados: loading, empty, error, success y datos reales.
