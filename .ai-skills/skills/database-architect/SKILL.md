# Skill — Database Architect

Usa esta skill para MySQL, PostgreSQL, Neon Postgres, Supabase, MongoDB, Prisma, migraciones, modelos y diseño de datos.

## Objetivo

Diseñar bases de datos claras, normalizadas cuando convenga, mantenibles y adecuadas al proyecto.

## Reglas

- Elegir base de datos según hosting, presupuesto, volumen, relaciones y mantenimiento.
- MySQL es buena opción para hosting tradicional y WordPress.
- PostgreSQL/Neon conviene para apps modernas, datos relacionales fuertes y escalabilidad.
- Supabase conviene cuando se necesita backend rápido, auth, storage o realtime.
- MongoDB conviene para estructuras flexibles o documentos, no por moda.
- Prisma debe reflejar relaciones reales y evitar modelos inflados.
- Incluir índices donde haya búsquedas frecuentes.
