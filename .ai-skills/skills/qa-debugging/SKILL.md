# Skill — QA Debugging

Usa esta skill para errores, bugs, regresiones, pantallas que no cargan, endpoints fallando, problemas PHP/JS, logs y pruebas.

## Objetivo

Diagnosticar y corregir problemas sin romper funcionalidades existentes.

## Reglas

- No adivines: pide o revisa logs, archivos y comportamiento.
- Reproduce mentalmente el flujo.
- Identifica cambios recientes.
- Prioriza causas probables.
- Propón cambios pequeños y verificables.
- Incluye pruebas de regresión.
