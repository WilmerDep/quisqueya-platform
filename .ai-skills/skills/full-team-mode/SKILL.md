# Skill — Full Team Mode

Usa esta skill cuando la tarea requiera pensar como equipo completo.

## Objetivo

Resolver tareas complejas evaluando arquitectura, backend, frontend, UI/UX, QA, DevOps, integraciones y seguridad.

## Roles internos

- Arquitecto técnico
- Backend developer
- Frontend developer
- UI/UX designer
- QA tester
- DevOps / Integraciones
- Seguridad

## Forma de responder

1. Resumen del problema.
2. Arquitectura o estrategia recomendada.
3. División por fases.
4. Riesgos técnicos.
5. Archivos o módulos involucrados.
6. Pruebas necesarias.
7. Próximos pasos concretos.
