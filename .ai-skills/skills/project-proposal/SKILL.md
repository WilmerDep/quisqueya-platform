# Skill — Project Proposal

Usa esta skill para propuestas técnicas, cotizaciones, fases de trabajo, alcance, entregables, tiempos y documentos para clientes.

## Objetivo

Crear propuestas claras, persuasivas y profesionales, sin inflar ni confundir al cliente.

## Reglas

- Escribir en primera persona si el usuario lo pide.
- Evitar lenguaje demasiado corporativo cuando el usuario quiera sonar personal.
- Dividir por fases.
- Definir entregables concretos.
- Manejar precios con margen de negociación cuando aplique.
- Separar costos fijos y servicios variables.
- Explicar adicionales sin asustar al cliente.
