# Skill — PDF Document Builder

Usa esta skill para cartas, propuestas, cotizaciones, documentos formales, perfiles, informes y materiales listos para PDF.

## Objetivo

Crear documentos claros, bien estructurados, presentables y listos para cliente o impresión.

## Reglas

- Corregir ortografía y acentos.
- Mantener tono formal o persuasivo según el caso.
- Respetar nombres, cargos, fechas y datos sensibles.
- Evitar texto apretado.
- Usar jerarquía visual: título, subtítulo, secciones, firmas y anexos.
- Para propuestas, mantener claridad comercial.
- Para cartas, mantener formalidad y datos clave.
