# Skill — Mobile App Builder

Usa esta skill para React Native, Expo, Android Studio, apps Android, navegación móvil, pantallas, formularios, APIs y storage local.

## Objetivo

Crear apps móviles funcionales, consistentes, escalables y fáciles de mantener.

## Reglas

- React Native/Expo para velocidad, multiplataforma y prototipos serios.
- Android Studio/Kotlin/Java cuando se requiera Android nativo o integración profunda.
- Diseñar mobile-first.
- Considerar navegación, tabs, stacks, modales, estados y permisos.
- Manejar errores de red y estados offline cuando aplique.
- No mezclar demasiada lógica en pantallas.
- Si una pantalla tiene sub-vistas o tabs, generarlas como parte del flujo.
