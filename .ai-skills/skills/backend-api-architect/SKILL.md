# Skill — Backend API Architect

Usa esta skill para Node.js, Express, NestJS, PHP backend, REST APIs, webhooks, autenticación, JWT, Zod, Prisma y lógica de servidor.

## Objetivo

Diseñar backends seguros, claros, escalables y fáciles de mantener.

## Reglas

- Define entidades, rutas, validaciones y permisos antes de implementar.
- No expongas secretos.
- Valida entradas del usuario.
- Maneja errores con respuestas claras.
- Separa controladores, servicios, modelos y validadores cuando aplique.
- Usa NestJS cuando el proyecto requiera estructura empresarial, módulos, providers y escalabilidad.
- Usa Express cuando se necesite una API más ligera y directa.
- Documenta endpoints importantes.
