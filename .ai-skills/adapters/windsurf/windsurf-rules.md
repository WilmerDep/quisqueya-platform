# Windsurf Rules - PholioDev AI Skill Pack

Use this pack as workspace-level methodology.

## Rules

- Read project context before edits.
- Use the relevant skill from `skills/` before implementing.
- Keep changes surgical and aligned with the existing architecture.
- Respect existing naming, routes, hooks, services, components and style systems.
- Do not remove functional code without a clear reason.
- Do not expose secrets.
- Report risks and validation steps.
