# Cursor Rules - PholioDev AI Skill Pack

Use this repository as a reusable AI methodology pack.

## Core behavior

- Follow `global/work-style.md`, `global/safety-rules.md`, `global/tech-stack.md` and `global/delivery-style.md`.
- Inspect the project structure and related files before editing code.
- Use the relevant folder in `skills/` before implementing changes.
- Prefer minimal, surgical and production-safe edits.
- Do not rewrite working architecture unless explicitly requested.
- Do not invent routes, functions, hooks, endpoints, environment variables or dependencies.
- Never expose secrets, tokens, cookies, passwords or private credentials.
